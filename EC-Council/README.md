# EC-Council

Ethical hacking and security-assessment study resources centered on the Certified Ethical Hacker (CEH) learning path. The [CEH directory](CEH/) contains 15 study modules, corresponding module quizzes, a midterm, and a timed final practice assessment.

## Topics Covered

- **Assessment foundations:** ethics, engagement methods, human and physical risks, reconnaissance, discovery, enumeration, and vulnerability prioritization.
- **Attack techniques and defenses:** system access, malware, network traffic analysis, web applications, wireless networks, and mobile devices.
- **Security technologies:** intrusion detection, firewalls, deception systems, cloud and IoT exposure, cryptography, and key management.

## Suggested Study Flow

Begin with the foundational modules and progress through the learning path in order. Complete each module's quiz, revisit weak areas, and use the midterm and final as cumulative checkpoints. The [CLI Labs](../CLIs/) offer additional practice with operating-system commands.

## Responsible Use

Apply security-testing techniques only in systems you own or environments where you have explicit authorization and a defined scope. Use isolated labs for practice and focus on understanding risks, documenting findings, and improving defenses.

These resources and assessments support learning; they are not official certification exams. Refer to your target exam's published objectives when planning certification preparation.
