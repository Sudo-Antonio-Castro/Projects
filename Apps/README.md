## Getting Started

Open the live directory and choose the category that matches your task. Browse its repository folder for the project files and review any included instructions before downloading or running a tool. Requirements, configuration, and permissions depend on the individual project.

## Usage Notes

Before running a script or executable, review its source or accompanying documentation and confirm the intended target system. Test administrative actions in a lab or on a non-production device first, use only the permissions required, and follow your organization's change-management procedures.

For supporting walkthroughs, visit the [IT Knowledge Base Articles](../IT-Knowledge-Base-Articles/). For command-line practice, explore the [CLI Labs](../CLIs/).
