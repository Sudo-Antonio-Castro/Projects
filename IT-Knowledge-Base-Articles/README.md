## How to Use the Articles

Read the article's audience, system information, review date, and caution notes before starting. Follow the procedure in order, adapting paths and environment-specific values where appropriate. Check the outcome before moving on, and use any validation guidance included in the article.

Use the **Read online** links for the formatted walkthroughs. The article-source links open the corresponding HTML files in the repository for inspection or editing.

## Usage Notes

Unlike the [CLI Labs](../CLIs/), commands copied from these articles into a real terminal can change the system or environment where they run. Review each command, confirm prerequisites and permissions, and test unfamiliar procedures in a lab first.

Wireless-security exercises are intended for owned or explicitly authorized networks within a defined testing scope. Software versions and installation methods can change; check the relevant vendor documentation when a procedure no longer matches your environment.
