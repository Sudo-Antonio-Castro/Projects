Implement Endpoint Security

Endpoint security combines hardening, anti-malware, behavioral monitoring, patching, and controlled execution on hosts.

Core Ideas

  • EPP, EDR, XDR, host firewalls, allowlisting, and anti-malware each address different parts of endpoint risk.
  • Hardening reduces unnecessary services, privileges, macros, and exposed applications.

Support Focus

  • Least functionality is an endpoint principle as much as a network principle.
  • Alerting without response workflow will not stop endpoint compromise.
Summary

The endpoint should be hardened before an attacker ever reaches it.

Security+ Exam Tip

Allowlisting is often the cleanest answer when the question is about preventing unauthorized code execution.

Mobile Device Hardening

Mobile endpoints require extra controls because they roam, use radios, carry personal data, and are easily lost or stolen.

Core Ideas

  • MDM, containerization, remote wipe, full-device encryption, and posture checks all matter.
  • Rooted, jailbroken, or sideloaded devices should be treated as higher risk.

Support Focus

  • Mobile security should protect corporate data without ignoring usability.
  • Separate personal and business content when BYOD is allowed.
Summary

Mobile hardening is about controlling data exposure as much as controlling the device itself.

Security+ Exam Tip

Containerization is a strong answer when you need to protect company data on employee-owned devices.
