BIOS and UEFI

Firmware initializes hardware and starts the boot process. Many startup and hardware-detection problems trace back to incorrect BIOS or UEFI settings.

Firmware Role

  • Legacy BIOS and modern UEFI both initialize the system, perform startup checks, and hand control to the operating system.
  • UEFI supports larger disks, graphical setup tools, mouse input, networking, and stronger boot security features.
  • POST behavior, beep codes, and startup indicators help you narrow down early hardware faults.

Common Settings

  • Technicians often adjust boot order, date and time, virtualization support, fan settings, onboard devices, and storage mode.
  • Secure Boot helps prevent unauthorized boot loaders, and TPM support is tied to device security and newer OS requirements.
  • If you miss the firmware key during startup, many systems let you reach UEFI options through an advanced restart from the operating system.

Recovery and Updates

  • A dead CMOS battery can cause clock resets, lost settings, or repeated configuration prompts.
  • Loading setup defaults is a useful first step when bad settings are suspected.
  • Firmware updates can fix compatibility or security issues, but they should be done carefully and only with the correct image for the board.
Summary

Startup problems often begin before Windows ever loads. Firmware settings, hardware detection, and secure boot behavior all belong in the first stage of diagnosis.

A+ Exam Tip

Know when to suspect boot order, when to suspect Secure Boot or TPM, and when a CMOS battery is the real reason settings keep resetting.

Power and Disk Issues

Power faults and storage failures can look similar from the user perspective, but each has its own pattern of symptoms and tests.

Power Problems

  • No power at all suggests outlet, power cable, surge protector, PSU, or motherboard faults.
  • Unexpected shutdowns can point to overheating, failing power delivery, or loose internal connections.
  • Intermittent starts or clicking relays are common clues when the PSU is unstable.

Storage Problems

  • Disk failures often appear as slow boots, missing files, SMART warnings, clicking sounds, or an OS that cannot load.
  • Check cable seating, drive detection in firmware, disk health data, and whether the failure is logical or physical.
  • Back up important data before running repair actions that could worsen the condition of a failing drive.

Tools and Response

  • Use known-good power cables, PSU testers, manufacturer diagnostics, SMART utilities, and recovery media when needed.
  • Separate hardware faults from file-system corruption before deciding on replacement or repair.
  • When a drive is failing physically, replacement is usually safer than repeated repair attempts.
Summary

Power issues disrupt the whole platform; disk issues usually show up as boot, file, or performance failures. The right first test saves time and protects data.

A+ Exam Tip

A+ favors symptom matching: no power, no boot, and no OS are not the same problem. Treat the PSU, motherboard, and disk as separate suspects.

System and Display Issues

System instability, memory errors, overheating, and graphics faults are common support calls. A+ expects you to connect symptoms to the most likely failing component.

System Stability

  • Blue screens, lockups, unexpected restarts, and failed POST events can result from RAM faults, overheating, bad drivers, or motherboard issues.
  • Pay attention to recent hardware changes, BIOS settings, and whether the failure happens only under load.
  • Reseating components and testing with known-good parts remain key troubleshooting methods.

Display Symptoms

  • No video can be caused by power problems, cable faults, wrong input selection, failed graphics hardware, or incorrect display settings.
  • Artifacts, flicker, dim output, and color distortion can point to the cable, panel, backlight, GPU, or a failing display controller.
  • Incorrect resolution, stretched output, or missing external displays are often tied to driver or configuration issues.

Thermal and Peripheral Clues

  • Overheating may trigger throttling, shutdowns, loud fans, or poor performance.
  • Dust buildup, failed fans, dried thermal paste, and blocked airflow are common root causes.
  • Touchscreens, webcams, speakers, and external monitors should also be checked as separate devices rather than assuming one global fault.
Summary

System problems rarely stay isolated. A single failing component can appear as crashes, thermal symptoms, and display instability all at once.

A+ Exam Tip

When the symptom is visual, do not jump straight to the monitor. The source device, adapter, driver, and cable are just as important.
