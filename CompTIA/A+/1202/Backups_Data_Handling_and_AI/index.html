Data Backup & Recovery

Backups are useful only when recovery is realistic and tested.

Core Ideas

  • Common backup methods include full, incremental, and differential jobs.
  • Retention plans and schedules should match business needs.
  • Restore testing matters because successful backups do not guarantee recovery.

Support Focus

  • Protect backups from the same disaster that could affect the primary data.
  • Users should not store critical business data only on one local device when managed storage exists.
  • Recovery planning matters as much as backup creation.
Summary

Backups are successful only when recovery is documented and tested.

A+ Exam Tip

Incremental backups are smaller, but recovery chains can be longer.

Data Handling Best Practices

Support technicians regularly touch sensitive data, so exposure should be minimized.

Core Ideas

  • Treat data according to policy, law, and the minimum needed to do the job.
  • Use approved storage, transfer, retention, and disposal procedures.
  • Ticket notes should not contain unnecessary sensitive information.

Support Focus

  • Portable media, screenshots, and printed output can all become data-loss risks.
  • Escalate suspected leakage or mishandling under incident procedures.
  • Classification helps determine how data should be stored and shared.
Summary

Most data security failures come from everyday handling mistakes, not dramatic attacks.

A+ Exam Tip

See only what you need, store only what is necessary, and share only through approved channels.

Artificial Intelligence Basics

AI tools can improve productivity, but privacy and validation still matter.

Core Ideas

  • Public AI services may process prompts through cloud-hosted platforms.
  • Private AI models may use internal data and require strong access controls.
  • AI output can be useful but still needs human review.

Support Focus

  • Sensitive data entered into AI tools can leak if governance is weak.
  • Prompt injection attempts can manipulate AI behavior or expose data.
  • AI use should follow company policy for confidential information.
Summary

Treat AI like any other cloud-connected service: useful, but not trusted blindly.

A+ Exam Tip

Validation and privacy are the two biggest AI themes on Core 2.
