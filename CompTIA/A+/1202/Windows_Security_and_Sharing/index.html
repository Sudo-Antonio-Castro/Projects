Logical Security Concepts

Most access problems are identity or permission problems before they are hardware problems.

Core Ideas

  • Authentication verifies identity; authorization determines access.
  • Least privilege reduces unnecessary exposure.
  • Password policy, lockout thresholds, and MFA lower account risk.

Support Focus

  • Support tickets often involve credentials, permissions, or reachability.
  • Local, cloud, and directory-backed accounts behave differently.
  • Security settings should balance usability and risk reduction.
Summary

Separate authentication from authorization in every access-control scenario.

A+ Exam Tip

Least privilege and MFA are common Core 2 themes.

Windows Security Settings

Windows includes built-in protections for malware, traffic filtering, elevation, and encryption.

Core Ideas

  • Windows Security centralizes anti-malware, firewall, and device security status.
  • User Account Control helps separate standard tasks from elevated admin actions.
  • BitLocker, Secure Boot, and TPM-backed protections strengthen endpoint trust.

Support Focus

  • Review update and security status before assuming the system is compliant.
  • Security controls should be documented and consistent across similar devices.
  • Repeated prompts or disabled protections often indicate a real issue.
Summary

Windows security is layered, not a single setting.

A+ Exam Tip

Secure Boot and TPM often appear in startup and encryption scenarios.

Windows Shares & Permissions

Shared data is useful, but only when access is intentionally controlled.

Core Ideas

  • Share permissions affect network access; NTFS permissions affect file system access.
  • Effective access is limited by the most restrictive combined result.
  • Read, change, and full control should be assigned carefully.

Support Focus

  • If users can see a share but not modify data, compare share and NTFS rights.
  • Mapped drive issues can also involve credentials or path changes.
  • Shared resources should follow least privilege.
Summary

Permission troubleshooting means comparing identity, share rights, and NTFS rights together.

A+ Exam Tip

Do not assume share permissions alone explain access.
