# CLIs

Interactive command-line practice labs for Linux, Windows PowerShell, and the macOS Terminal. Work through guided scenarios in a terminal-style interface to build familiarity with common commands and IT administration workflows.

## How to Use

1. Open a lab, select a scenario, and read the current task.
2. Enter the command in the simulated terminal and press **Enter**. Use **Hint** for guidance or **Reveal** to show the expected answer and advance the task.
3. Review the completed steps. Use **Reset scenario** to repeat the current exercise or **Reset all** to clear that lab's progress.

## How the Labs Work

These are browser-based simulations, not connections to your computer's shell. Each task checks your entry against supported answers and displays prepared output. The labs do not execute the entered commands on your device or implement every command a real shell supports.

Progress is saved in browser local storage rather than a shared account. Continue in the same browser and site location; progress does not automatically follow you to another browser or device.

When working with a local copy, preserve the repository's folder structure and shared [assets](../assets/) so the pages retain their styling and navigation.
